# 个人发票管理与月度报销

平时积累 PDF 发票，分「餐补」「其他」两类管理。餐补按「可报销天数 × 每日标准」自动凑票，其他发票直接勾选，两部分合并为一张月度报销单，统一打印、导出和确认报销。每日标准默认 **25 元**。

## Windows 直接运行（无需安装 Python）

在仓库的 **Actions → Build Windows EXE** 中打开最新成功的构建，下载底部 **InvoiceManager-Windows-x64**，解压后双击 `InvoiceManager.exe`。适用于 Windows 10/11 64 位，无需 Python、pip 或 SumatraPDF。首次启动单文件程序需要解压运行库，请稍候。

程序会在 EXE 旁创建 `data/`，保存数据库和发票原件。请放在可写的普通文件夹中。更新时关闭程序，只替换 EXE，保留 `data/`。

从源码版迁移旧数据：关闭程序，将原来的 `invoices.db` 和 `managed_pdfs/` 一起**复制**到 EXE 旁的 `data/` 中；旧票据若仍保存在 `invoices/`，也复制到 `data/invoices/`。复制前请备份，勿覆盖另一份正在使用的数据库。新程序不会自动打包或上传你的发票数据。

## 自己打包 EXE

构建电脑需要 Windows 和 Python，双击根目录 `build_windows.bat`。输出为 `dist/InvoiceManager.exe`，可以单独复制到其他 Windows 电脑运行。或执行：

```powershell
py tools/build_windows.py
```

GitHub Actions 会在相关代码推送后自动构建，也可以手动运行。构建包括应用测试和打包后 EXE 自检；只有通过后才上传下载文件。

## 开发运行

源码入口只有 `app.py`，旧的 `main.py` 及命令行录入脚本已移除。`database.py`、`read_invoice.py` 等是应用必需模块，不能删除。`windows_print.ps1` 是系统打印组件，打包时会内置到 EXE 中。

```powershell
py -m pip install -r requirements.txt
py app.py
```

源码版继续使用根目录数据库，已有数据位置不变。

## 日常积累

- 点击「导入餐补」或「导入其他」后直接多选 PDF，按按钮对应分类入库；「扫描文件夹」菜单可选择扫描为餐补或其他，再选择持续存放新票的目录，再次扫描时按发票号去重，改文件名也不重复入库。
- 自动解析发票号、购买方、销售方、日期、价税合计；缺失字段或无文字的扫描件会报告失败原因，其他文件继续处理。扫描图片需先 OCR。支持20位号码的数电发票，以及带10/12位代码和8位号码的传统电子普通发票；传统票按「代码＋号码」去重，界面显示真实号码及代码，PDF 导出名使用真实号码。文本提取异常时会自动尝试备用提取器。
- 成功导入的原 PDF 按发票号复制到 `managed_pdfs/`，保留原始内容。原来数据库中的历史文件可重新导入一次，自动去重并补齐保管副本。不会改写备注、打印或使用状态。
- 库存可按发票号、购买方、销售方、备注搜索，并按打印和使用状态筛选。选择一张后可打开原 PDF；双击库存发票行弹窗修改备注，可保存、取消或清空。库存底部「删除记录」支持删除所选数据库记录，需弹窗确认，保留原始 PDF；已预留、已使用及关联报销单的记录不可删除。报销清单默认选中第一张，点击「打开原 PDF」或双击任意发票行可打开对应原件；复选框只控制打印和导出。

## 两类发票库存

- **餐补**：参与按天数和每日金额的自动凑票。
- **其他**：报销时直接勾选需要的发票，按真实金额计入本月报销，不参与餐补凑票。无需填写用途或另附付款凭证。
- 库存页右上角直接选择「导入餐补 / 导入其他」；扫描文件夹也分两类入口，无需先设置分类。导入结束后自动显示对应分类库存；重复发票仍按发票号去重，不会被重复导入改分类。
- 分类筛选可查看全部、餐补或其他。选中若干张后点击「移至餐补 / 移至其他」可批量调整；已预留、已使用及关联有效报销单的票不能调整分类。
- 旧数据库首次启动自动升级，已有发票默认归为餐补，原有备注、打印状态和报销历史保留。

## 每月报销：一个窗口完成

程序打开默认进入「本月报销」。库存和历史分别放在同一主窗口的另外两个页签，主要报销流程均在主窗口完成，仅取消报销单使用弹窗二次确认。页面常驻信息仅保留金额摘要和操作按钮，必要的确认、错误与操作结果在页面内简短显示。

1. 填写月份 `YYYY-MM`、实际可报销天数、每日金额（默认 25 元），目标实时显示。
2. 有其他发票要报销时，点击「选择其他发票」展开清单，可全选、取消全选或逐张点击大号勾选框；没有则跳过。点击 **「生成方案」** 后，餐补自动凑票，再加上勾选的其他发票，分类、金额和差额直接显示在当前页面。修改目标或其他发票勾选后，旧方案自动失效，需要重新生成。只报其他发票时，天数填 0。
3. 点击页面上的 **「确认方案并预留」**，在清单原位置进入打印 / 导出区，不弹窗、不切换窗口。确认前不占用库存；确认后两类发票一起预留。
4. 发票默认全选，可点击第一列方框或按空格调整；支持全选和取消全选。勾选仅用于打印 / 导出，不负责凑票，也不改变整单组成。
5. 点击打印后，在同一页面核对出纸结果，再点击 **「全部实际打印成功」**；取消、未出纸、部分失败点击「取消 / 未全部成功」，不改打印状态。
6. 点击 **「确认已报销」**，页面内显示整单使用提示，再点击「确认整单已报销」才标记使用。取消未使用报销单使用弹窗二次确认：释放预留发票，删除该报销单及明细记录，清空当前清单和历史中的这条记录；发票原件、备注和打印状态保留。
7. 「报销历史」页签选中单据后，点击「继续办理 / 查看明细」，在本月报销页中继续打印、导出或确认报销。已完成单据仍可查看、导出和重打。

仅选择文件、选择导出位置、选择打印机使用操作系统对话框；打开原 PDF 会使用系统阅读器。备注编辑和删除库存记录使用弹窗；导入错误详情、操作成功或失败提示在主窗口内显示。

每张票只能整张使用一次，没有拆分或剩余额度。已预留、已使用、不可用的票不会参加自动凑票。已使用的票不能再恢复库存；关联有效报销单的发票只能通过整单操作改变使用状态。

## 批量打印

Windows 使用系统自带的 PowerShell、.NET 打印对话框，无需安装 SumatraPDF。先在 Windows 设置中添加打印机，并安装支持 A5 的完整驱动；项目依赖需执行 `python -m pip install -r requirements.txt` 安装。Linux/macOS 使用系统 CUPS 的 `lp`，需先配置默认打印机。

在本月报销页的报销单清单中，勾选发票后点击「批量打印 / 重新打印」：

- 生成独立的 **A5、横向、黑白、每张一页** 打印副本，以 5 mm 边距等比例完整缩放，原 PDF 不改动。
- Windows 打开系统打印对话框，选定打印机后按 A5、横向、黑白和完整缩放打印；不支持 A5 的驱动会明确提示。取消系统打印对话框不会进入打印成功确认。请核对打印机及纸张。Linux/macOS 提交至默认打印机。
- 多页发票将拒绝自动打印并提示人工核对，避免悄悄漏页或裁切。
- 命令返回成功只代表打印程序接收，**必须实际检查出纸后点击页面内的「全部实际打印成功」，才会标记已打印**。取消、失败、部分成功时点击「取消 / 未全部成功」，状态不变；可重新勾选需要的票重打。
- 打印与确认报销使用相互独立。云环境仅验证打印文件和交互逻辑，没有实体打印机验证。

## 公司命名导出

点击「勾选 PDF 打包导出」，选择 ZIP 保存位置。默认压缩包名按报销月份、本单目标、本次勾选发票的真实金额合计、实际减目标的差额生成，例如：

```text
2026-10应报销：100实际报销：90差额-10.zip
```

Windows 不允许英文冒号，所以使用全角冒号 `：`。只勾选部分票时，实际金额与差额按该部分计算。ZIP 内每张 PDF 文件名为：

```text
发票号_销售方公司名称_价税合计.pdf
26952000004515245716_广酒（深圳）餐饮管理有限公司_428.pdf
```

报销单应报销额 = 餐补天数 × 每日金额 + 本单其他发票金额；实际金额 = 本次导出所勾选的两类发票合计。其他发票不会影响餐补凑票的金额差额。

金额保留真实数值，去除无意义的小数末尾零；销售方名称中 Windows 不允许的文件名字符替换为下划线。ZIP 内是原始 PDF 字节内容，不是打印转换件。导出不改变打印和使用状态。

## 数据与备份

数据库 `invoices.db` 保存库存、备注、状态及报销历史；`managed_pdfs/` 保存个人发票原件。关闭程序后仍保留。迁移、备份时请一起复制这两者，勿仅复制 Git 代码。`managed_pdfs/` 已忽略，不会自动上传 GitHub。旧示例数据库和发票仍保持现有 Git 跟踪方式。

## 测试

```powershell
python -m unittest discover -s tests -v
```

已配置的云环境中，使用 `/workspace/invoice-manager-env/bin/python`；虚拟显示器启动后加 `DISPLAY=:99`。
